# Mobile Android Dev Runbook

## Current Decision

Use an Android development build, not Play Store Expo Go.

The mobile app is on Expo SDK 55. The OnePlus currently has Expo Go 54.0.8 from
the Play Store, so Expo Go reports the project as incompatible. A dev-client
build avoids that mismatch and is also the right path for future native voice
work.

## Repo Changes Needed For This Path

`apps/mobile/package.json` includes:

```json
"expo-dev-client": "~55.0.34"
```

`apps/mobile/metro.config.js` keeps Metro hierarchical lookup enabled so pnpm
Expo transitive dependencies resolve correctly.

`apps/mobile/android/` is generated by `expo run:android` and is ignored by git.

## Physical OnePlus Over Wi-Fi

On the phone:

1. Enable Developer options.
2. Open Developer options.
3. Enable Wireless debugging.
4. Tap Wireless debugging.
5. Tap Pair device with pairing code.

On the Mac:

```bash
adb pair PHONE_IP:PAIRING_PORT
```

Enter the pairing code shown on the phone.

Then close the pairing-code popup on the phone. On the main Wireless debugging
screen, copy the separate IP address and port, then run:

```bash
adb connect PHONE_IP:CONNECT_PORT
adb devices -l
```

Expected:

```text
PHONE_IP:CONNECT_PORT device
```

Optional Wi-Fi reachability check:

```bash
adb -s PHONE_IP:CONNECT_PORT shell ping -c 1 192.168.1.2
```

Set the mobile app to call the server on the Mac Wi-Fi IP:

```bash
cd /Users/shadevkumar/projects/uno
printf 'EXPO_PUBLIC_SOCKET_URL=http://192.168.1.2:4001\n' > apps/mobile/.env.local
```

First-time install/build on the OnePlus:

```bash
cd /Users/shadevkumar/projects/uno
pnpm --filter mobile exec expo run:android --device CPH2717
```

If Expo asks which device to use, choose the `CPH2717` OnePlus.

After the dev-client app is installed, normal JS/dev-server runs are:

```bash
cd /Users/shadevkumar/projects/uno
pnpm --filter mobile exec expo start --dev-client --lan --clear
```

Open the installed `uno` app on the OnePlus and connect to the shown LAN dev
server URL.

## Android Emulator Option

Set the mobile app to call the server through the Android emulator host alias:

```bash
cd /Users/shadevkumar/projects/uno
printf 'EXPO_PUBLIC_SOCKET_URL=http://10.0.2.2:4001\n' > apps/mobile/.env.local
```

Start the emulator:

```bash
emulator -avd Pixel_8
adb devices -l
```

Build/install on emulator:

```bash
cd /Users/shadevkumar/projects/uno
pnpm --filter mobile exec expo run:android
```

If both the phone and emulator are connected and Expo targets the wrong one,
temporarily disconnect the phone:

```bash
adb disconnect 192.168.1.5:44091
pnpm --filter mobile exec expo run:android
```

After the dev-client app is installed on the emulator:

```bash
pnpm --filter mobile exec expo start --dev-client --android --clear
```
